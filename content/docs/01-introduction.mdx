# מה זה Claude Code, ולמה זה משנה את המשחק?

נניח שיש לכם רעיון לאתר קטן: דף מתכונים משפחתי, עמוד לעסק או כלי שמסדר את התמונות מהטיול. עד לא מזמן היו שתי אפשרויות: ללמוד לתכנת, או לשלם למישהו שיודע.

Claude Code הוא אפשרות שלישית. **זה עוזר בינה מלאכותית שעובד ישירות על המחשב שלכם**: אתם מסבירים במילים פשוטות מה אתם רוצים, והוא כותב את הקבצים, מריץ אותם, בודק שהכול עובד ומתקן כשמשהו נשבר. אתם נשארים בתפקיד המנהלים: מחליטים, מאשרים ומכוונים.

<Callout type="note" title="מה תדעו בסוף הפרק">
- מה Claude Code עושה, ובמה הוא שונה מצ'אט רגיל כמו ChatGPT או Claude באתר.
- איך נראית העבודה איתו בפועל.
- למה כדאי לעבוד איתו ביחד עם עורך הקוד Cursor.
</Callout>

## Claude Code במשפט אחד

Claude Code הוא **סוכן תכנות** (באנגלית: Agent) שגר בתוך **הטרמינל**, החלון שבו מקלידים פקודות למחשב. "סוכן" אומר שהוא לא רק עונה על שאלות, אלא **עושה פעולות**: פותח קבצים, משנה אותם, מריץ תוכנות ובודק את התוצאה.

<Callout type="tip" title="אל תיבהלו מהמילה טרמינל">
הטרמינל הוא פשוט חלון טקסט. בקורס הזה תצטרכו בו בערך חמש פקודות, וכולן מוסברות צעד אחר צעד בפרקים 2 ו-3. רוב הזמן תכתבו ל-Claude בעברית רגילה.
</Callout>

Claude Code זמין גם כתוסף לעורכי קוד, כאפליקציה למחשב ובדפדפן. בקורס נתמקד בגרסת הטרמינל, כי היא הבסיס לכל השאר וכי היא משתלבת הכי טוב עם Cursor.

## צ'אט רגיל מול סוכן בטרמינל

ההבדל הכי חשוב להבין: צ'אט **ממליץ**, סוכן **מבצע**.

נניח שבאתר שלכם כפתור "שלח" לא עובד. כך זה נראה בשתי הדרכים:

### עם צ'אט רגיל

1. מעתיקים את הקוד הרלוונטי (אם בכלל יודעים איזה קוד רלוונטי) ומדביקים בצ'אט.
2. מקבלים הצעה לתיקון, מעתיקים אותה בחזרה לקובץ הנכון.
3. מריצים, רואים הודעת שגיאה חדשה, מעתיקים אותה לצ'אט.
4. חוזרים על זה עד שזה עובד, או עד שנשבר לכם.

### עם Claude Code

<Prompt>כפתור השליחה בטופס יצירת קשר לא עושה כלום. תמצא למה ותתקן.</Prompt>

ומשם Claude עובד לבד:

1. **קורא את הקבצים** בתיקיית הפרויקט ומוצא איפה נמצא הטופס.
2. **מריץ פקודות בטרמינל**, למשל מפעיל את האתר כדי לראות את השגיאה בעצמו.
3. **עורך את הקובץ** הנכון, ומבקש את אישורכם לפני השינוי.
4. **בודק שוב** שהתיקון באמת עבד.
5. אם תבקשו, **שומר את העבודה ב-Git**: יוצר ענף (Branch) חדש לתיקון וכותב תיאור מסודר של מה שהשתנה.

| | צ'אט רגיל | Claude Code |
| --- | --- | --- |
| רואה את הקבצים שלכם | רק מה שהדבקתם | קורא את כל הפרויקט לפי הצורך |
| משנה קבצים | אתם מעתיקים ומדביקים | עורך בעצמו, באישורכם |
| מריץ פקודות ובודק תוצאות | לא | כן: מתקין, מריץ, בודק שגיאות |
| עבודה עם Git | נותן לכם פקודות להעתיק | יוצר ענפים, שומר שינויים וכותב תיאורים |
| מי עושה את העבודה השחורה | אתם | הוא, ואתם מפקחים |

<Callout type="info" title="איך הוא חושב">
Claude Code עובד בלולאה של שלושה שלבים: **אוסף מידע** (קורא קבצים, מחפש), **פועל** (עורך, מריץ) ו**בודק** (מריץ שוב, קורא שגיאות). הוא חוזר על הלולאה עד שהמשימה גמורה, ואתם יכולים לעצור אותו או לשנות כיוון בכל רגע.
</Callout>

## מה אפשר לעשות איתו?

הנה כמה דוגמאות לבקשות אמיתיות. שימו לב שאף אחת מהן לא דורשת לדעת לתכנת:

<Prompt>תבנה לי אתר פשוט עם עמוד לכל מתכון מהקובץ recipes.txt</Prompt>

<Prompt>תסביר לי בעברית פשוטה מה הפרויקט הזה עושה ואיך הוא בנוי</Prompt>

<Prompt>יש לי תיקייה עם 300 תמונות. תשנה את השמות שלהן לפי התאריך שבו צולמו</Prompt>

<Prompt>האתר נראה שבור בטלפון. תתקן את התצוגה למסכים קטנים</Prompt>

ובמילים אחרות, Claude Code טוב במיוחד ב:

- **לבנות דברים מתיאור**: מאתר שלם ועד כלי קטן שחוסך לכם עבודה ידנית.
- **למצוא ולתקן תקלות**: הוא קורא את הודעת השגיאה, מוצא את המקור ומתקן.
- **להסביר קוד קיים**: מצוין כשמקבלים פרויקט ממישהו אחר ולא מבינים מה קורה בו.
- **משימות משעממות**: לסדר קבצים, לעדכן טקסטים בהרבה מקומות, לכתוב תיעוד.

## אתם תמיד בשליטה

הפחד הכי נפוץ אצל מתחילים: "מה אם הוא יעשה משהו שאני לא רוצה?" ככה Claude Code שומר עליכם:

- **הרשאות**: אפשר להגדיר אותו כך שיבקש אישור לפני כל שינוי בקובץ ולפני כל פקודה. בפרק 3 נלמד בדיוק איך לקרוא את בקשות האישור ומתי להגיד "כן".
- **עצירה מיידית**: לחיצה על `Esc` עוצרת אותו באמצע פעולה.
- **חזרה אחורה**: Claude Code שומר נקודות ביקורת, וכך אפשר להחזיר קבצים שהוא שינה למצב הקודם.
- **הוא עובד רק בתיקייה שבחרתם**: מפעילים אותו בתוך תיקיית פרויקט מסוימת, והוא עובד בתוכה.

<Callout type="warning" title="כן, צריך עדיין שיקול דעת">
Claude חכם מאוד אבל לא מושלם. לפעמים הוא טועה או מבין לא נכון. לכן ההרגל הכי חשוב שתלמדו בקורס: **לקרוא מה הוא עומד לעשות לפני שמאשרים**. זה לוקח שניות וחוסך הרבה כאב ראש.
</Callout>

## למה Cursor ו-Claude Code הם צמד מנצח

[Cursor](https://cursor.com) הוא **עורך קוד**: תוכנה שמציגה את הקבצים של הפרויקט בצורה נוחה, עם עץ תיקיות, צבעים שמקלים על הקריאה ובינה מלאכותית משלו. הוא מבוסס על VS Code, עורך הקוד הפופולרי בעולם.

אז למה צריך את שניהם? כי כל אחד מהם טוב בדבר אחר:

| | Cursor (העורך) | Claude Code (הסוכן) |
| --- | --- | --- |
| התפקיד | העיניים: לראות ולהבין | הידיים: לבצע |
| מצוין ב | לראות את כל הקבצים, לעקוב אחרי שינויים, תיקונים קטנים | משימות גדולות שנוגעות בהרבה קבצים, הרצת פקודות, תיקון תקלות |
| איך עובדים איתו | מקליקים, גוללים, עורכים ידנית | מתארים בעברית מה רוצים |

ככה נראית העבודה המשולבת:

1. פותחים את תיקיית הפרויקט ב-Cursor.
2. פותחים את הטרמינל **בתוך** Cursor ומפעילים בו את Claude Code. אפשר להשתמש גם בתוסף של Claude Code, ש-Cursor תומך בו כי הוא מבוסס על VS Code.
3. מבקשים מ-Claude משימה, ו**רואים בזמן אמת** את הקבצים משתנים בעורך שלידו.
4. משהו לא נראה לכם? פותחים את הקובץ, מסתכלים, ומבקשים תיקון או מתקנים לבד.

<Callout type="tip" title="למה זה כל כך עובד">
בלי עורך, עבודה עם סוכן בטרמינל מרגישה כמו לנהל עובד דרך הטלפון: הוא מספר לכם מה עשה, אבל אתם לא רואים. עם Cursor לצדו אתם יושבים איתו באותו חדר ורואים כל שינוי. פרק 5 מוקדש כולו לעבודה המשולבת הזאת.
</Callout>

## מה צריך כדי להתחיל?

- **מחשב** עם Windows 10 ומעלה, macOS 13 ומעלה, או Linux (למשל Ubuntu 20.04 ומעלה), עם לפחות 4GB זיכרון.
- **חיבור לאינטרנט**.
- **חשבון בתשלום**: מנוי Claude Pro, Max, Team או Enterprise, או חשבון Claude Console שמשלמים בו לפי שימוש. **המנוי החינמי של Claude לא כולל את Claude Code.** בפרק הבא נסביר את ההבדל בין האפשרויות.
- **סקרנות**. ידע בתכנות לא צריך.

<Callout type="info" title="מה הלאה">
בפרק הבא נתקין את Claude Code, עם הוראות נפרדות ל-Windows, ל-Mac ול-Linux, ונתחבר לחשבון. ההתקנה עצמה לוקחת כמה דקות.
</Callout>
