# מילון מושגים ודף עזר

כל המושגים והפקודות מהקורס, במקום אחד. חפשו מילה, או סננו לפי נושא: **מושגי יסוד**, **מתקדם** או **פקודות CLI**. ליד כל מושג יש קישור לפרק שבו הוא מוסבר לעומק.

<Callout type="tip" title="שמרו את הדף הזה">
הדף הזה נועד לחזור אליו. הוסיפו אותו למועדפים בדפדפן, וכשאתם נתקלים במילה לא מוכרת, באמצע עבודה או בשיחה עם Claude, חפשו אותה כאן.
</Callout>

## דף עזר מהיר: 10 הפקודות החשובות

```text title="להדפסה או לשמירה ליד המחשב"
claude              הפעלת Claude Code בתיקייה הנוכחית
claude -c           המשך השיחה האחרונה
Shift+Tab           החלפת מצב הרשאות
@file               צירוף קובץ לבקשה
!command            הרצת פקודת טרמינל בתוך השיחה
Esc / Esc Esc       עצירה / חזרה לנקודה קודמת
/clear              שיחה חדשה בין משימות
/compact            סיכום שיחה ארוכה כדי לפנות מקום
/context            מה תופס מקום בחלון ההקשר
/help               כל הפקודות
```
