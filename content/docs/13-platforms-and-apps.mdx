# האקוסיסטם של Claude: הטרמינל, אפליקציית הדסקטופ, תוסף הכרום והמובייל

לאורך הקורס עבדנו בעיקר בטרמינל, ובפרק 5 גם בתוך Cursor. אבל Claude Code לא גר רק שם. אותו "מנוע" זמין גם באפליקציה למחשב, בדפדפן, בטלפון, ואפילו מתוך Chrome, והחלק הכי מעניין הוא שאפשר **להעביר עבודה ביניהם**: להתחיל משימה בטלפון באוטובוס, ולהמשיך אותה בטרמינל כשמגיעים הביתה.

<Callout type="note" title="מה תלמדו בפרק">
- את כל הממשקים של Claude Code, ומה ההבדל ביניהם.
- את ההבחנה הכי חשובה: **איפה הקוד רץ**, אצלכם או בענן.
- את אפליקציית הדסקטופ לעומק: סקירת שינויים ויזואלית וסשנים במקביל, בלי טרמינל.
- את תוסף הכרום: Claude שבודק את האתר שלכם בדפדפן אמיתי.
- את המובייל: לשלוח משימות מהטלפון ולשלוט מרחוק בסשן שרץ על המחשב.
- איך מעבירים סשנים בין הממשקים, כולל `claude --teleport`.
</Callout>

כמעט כל החלטה בפרק הזה נגזרת מהשאלה הזאת.

## אפליקציית ה-Desktop: Claude Code בלי טרמינל

אפליקציית Claude למחשב כוללת שלוש לשוניות: **Chat**, **Cowork** ו-**Code**. הלשונית **Code** היא Claude Code מלא, עם ממשק גרפי. לא צריך להתקין את גרסת הטרמינל בנפרד.

### התקנה

הורידו מ-[claude.com/download](https://claude.com/download) (macOS, Windows, ו-Linux בגרסת בטא), התחברו, ולחצו על הלשונית **Code**.

### פותחים סשן

מתחת לתיבת הכתיבה יש שורה של בחירות. מגדירים אותן **לפני** ההודעה הראשונה:

| בחירה | מה בוחרים |
| --- | --- |
| **סביבה** (Environment) | **Local** (במחשב), **Cloud** (בענן) או **SSH** (שרת מרוחק). ב-Windows יש גם WSL |
| **תיקיית פרויקט** | התיקייה לעבוד בה. בסשן ענן בוחרים מאגר מ-GitHub |
| **מצב הרשאות** | Manual, Accept edits, Plan או Auto, בדיוק כמו `Shift + Tab` בטרמינל |
| **מודל** | איזה מודל של Claude |

### סקירת שינויים ויזואלית

זה היתרון הגדול של האפליקציה, ומה שהופך אותה לאידיאלית למי שלא מרגיש בנוח בטרמינל:

1. אחרי ש-Claude עשה שינויים, לחצו על מונה השורות (למשל `+12 -1`) בכרטיס **Changes**, או על **Changes** בשורת הכותרת.
2. עוברים על השינויים קובץ אחרי קובץ.
3. **לוחצים על שורה** כדי להוסיף לה הערה, למשל "הכפתור הזה צריך להיות גדול יותר", ולוחצים Enter.
4. כשסיימתם, שולחים את כל ההערות יחד עם `Cmd + Enter` (ב-Windows: `Ctrl + Enter`). Claude מיישם אותן ומציג את התוצאה כשינוי חדש.

<Callout type="tip" title="סקירת קוד בלחיצה">
הקלידו `/code-review` בתיבת הכתיבה. התוצאה מופיעה ככרטיס **Code review** עם שני כפתורים: **Walk through in diff**, שמראה כל ממצא במקום שלו בקוד, ו-**Apply fixes**, שמתקן.
</Callout>

### סשנים במקביל

- **+ New** (או `Cmd/Ctrl + N`) פותח סשן חדש, ו-`Ctrl + Tab` עובר בין סשנים.
- החזיקו `Cmd` (ב-Windows: `Ctrl`) ולחצו על סשן ברשימה, כדי לראות **שני סשנים זה לצד זה**.
- הפעילו **Worktree** בבחירת התיקייה, וכל סשן יעבוד על עותק נפרד של הפרויקט (Git worktree), בלי שהסשנים יתנגשו. לכן אפשר, למשל, לבנות פיצ'ר בסשן אחד ולתקן באג בסשן אחר, באותו זמן.

<Callout type="warning" title="לפני שמארכבים סשן עם Worktree">
שינויים שלא נשמרו ב-Git בתוך worktree יכולים ללכת לאיבוד כשמארכבים את הסשן (**Archive**). תמיד שמרו קודם.
</Callout>

### דפדפן מובנה

Claude יכול להפעיל את שרת הפיתוח ולפתוח את האתר בחלונית **Browser** בתוך האפליקציה (`Cmd/Ctrl + Shift + B`): לצלם מסך, ללחוץ על כפתורים ולמלא טפסים, כדי לוודא שהשינוי עובד. את פקודת ההרצה מגדירים בקובץ `.claude/launch.json`:

```json title=".claude/launch.json"
{
  "version": "0.0.1",
  "configurations": [
    {
      "name": "grandma-recipes",
      "runtimeExecutable": "npm",
      "runtimeArgs": ["run", "dev"],
      "port": 3000
    }
  ]
}
```

### מהטרמינל לאפליקציה, ובחזרה

התחלתם בטרמינל ורוצים לסקור את השינויים בממשק הוויזואלי? בתוך Claude Code בטרמינל:

```text title="בתוך Claude Code"
/desktop
```

הסשן ממשיך באפליקציה, עם כל השיחה. זמין ב-macOS וב-Windows (x64), ודורש מנוי claude.ai. ובכיוון השני, מתוך האפליקציה: בתפריט הסשן (החץ ליד הכותרת) בוחרים **Open in**, ומשם אפשר להעביר את הסשן לענן (**Cloud**), לעורך קוד או לסייר הקבצים.

## תוסף Chrome: Claude שבודק את האתר בדפדפן אמיתי

עד עכשיו, כשרצינו לבדוק שהאתר עובד, פתחנו את הדפדפן **בעצמנו**, ניסינו, והעתקנו שגיאות ל-Claude. עם תוסף **Claude in Chrome**, Claude יכול לעשות את זה לבד: לפתוח את האתר, ללחוץ, למלא טפסים, לקרוא את שגיאות הקונסול, ואז לחזור לקוד ולתקן.

### התקנה וחיבור

1. התקינו את [Claude in Chrome](https://chromewebstore.google.com/detail/claude/fcoeoabgfenejglbffodgkkbkcdhcgfn) מחנות התוספים של Chrome, והתחברו עם אותו חשבון claude.ai שבו אתם מחוברים ל-Claude Code. עובד ב-Chrome, ב-Edge ובדפדפנים דומים, אבל לא ב-WSL.
2. הפעילו את Claude Code עם הדגל `--chrome`:

```bash title="בטרמינל"
claude --chrome
```

3. בפעם הראשונה תופיע הודעת הסבר על החיבור ועל הרשאות לאתרים. לחצו Enter.
4. כדי לבדוק את מצב החיבור, להתחבר מחדש או לנהל הרשאות, הריצו בכל רגע:

```text title="בתוך Claude Code"
/chrome
```

החיבור תקין כשמופיעים **Status: Enabled** ו-**Extension: Installed**.

<Callout type="tip" title="Chrome כברירת מחדל? רק אם צריך">
ב-`/chrome` אפשר לבחור **Enabled by default**, ואז לא צריך את הדגל `--chrome`. אבל כלי הדפדפן ייטענו בכל שיחה ויתפסו מקום בחלון ההקשר (פרק 12). אם אתם לא בודקים אתרים כל יום, עדיף להפעיל עם `--chrome` רק כשצריך.
</Callout>

## Web ו-Cloud: משימות שרצות גם כשהמחשב כבוי

ב-[claude.ai/code](https://claude.ai/code) מריצים Claude Code **בענן**: מחשב וירטואלי מוריד את המאגר שלכם מ-GitHub, עובד עליו, ויכול לפתוח Pull Request. הסשן ממשיך לרוץ גם כשסוגרים את הלפטופ, ואפשר להציץ בו מכל מכשיר.

**ההתחלה:** נכנסים ל-claude.ai/code, מחברים את GitHub, בוחרים מאגר ומתארים משימה.

**מתי זה מצוין:**

- משימה ארוכה שלא צריכה אתכם צמודים: "תעדכן את כל התלויות ותתקן מה שנשבר".
- כמה משימות **במקביל**, כל אחת בסשן ענן משלה.
- עבודה על מאגר שאין לכם במחשב.

אפשר גם לשלוח משימה לענן **ישירות מהטרמינל**:

```bash title="בטרמינל"
claude --cloud "תוסיף לאתר דף אודות עם סיפור המשפחה, ותפתח PR"
```

<Callout type="note" title="הענן מוריד מ-GitHub, לא מהמחשב שלכם">
סשן ענן מוריד את הענף הנוכחי **מ-GitHub**. אם יש לכם שמירות שעוד לא דחפתם, הן לא יהיו שם. לפני `--cloud`, תמיד `git push`.
</Callout>

כמה משימות בבת אחת, כל אחת בסשן נפרד:

```bash title="בטרמינל"
claude --cloud "תוסיף בדיקות למחשבון המנות"
claude --cloud "תעדכן את README.md לפי מבנה הפרויקט"
claude --cloud "תשפר את הנגישות בדף המתכון"
```

<Callout type="tip" title="PR שמתקן את עצמו">
אם אפליקציית Claude מותקנת על המאגר ב-GitHub, אפשר לבקש מ-Claude **לעקוב אחרי Pull Request**: כשבדיקה אוטומטית נכשלת, או כשמישהו כותב הערה, Claude חוקר ודוחף תיקון. מהטרמינל, על הענף של ה-PR: `/autofix-pr`.
</Callout>

## Teleport: מהענן לטרמינל

התחלתם משימה בענן, מהדפדפן או מהטלפון, ועכשיו אתם ליד המחשב ורוצים להמשיך מקומית? **Teleport** מושך את הסשן לטרמינל: את הענף, את הקוד ואת כל השיחה.

```bash title="בטרמינל, בתוך תיקיית המאגר"
# בוחרים סשן מרשימה
claude --teleport

# או ישירות לפי מזהה
claude --teleport session_01AbC...
```

ואם אתם כבר בתוך Claude Code, אפשר `/teleport` (או בקיצור `/tp`).

| דרישה | מה זה אומר |
| --- | --- |
| **מצב Git נקי** | אין שינויים שלא נשמרו. אם יש, Claude Code יציע להחביא אותם (stash) |
| **אותו מאגר** | מריצים מתוך עותק של **אותו** מאגר, לא מ-fork |
| **הענף ב-GitHub** | הענף של סשן הענן נדחף, ו-Teleport מוריד אותו לבד |
| **אותו חשבון** | מחוברים לאותו חשבון claude.ai |

<Callout type="info" title="Teleport יוצר עותק, לא חיבור">
אחרי ה-Teleport, לטרמינל יש עותק משלו של הסשן. עבודה חדשה בטרמינל **לא** תופיע בסשן שבענן. וזה עובד רק בכיוון אחד: מהענן לטרמינל. אי אפשר "לדחוף" סשן קיים מהטרמינל לענן, אבל אפשר לפתוח משימה חדשה עם `--cloud`.
</Callout>

## מובייל: Claude Code בכיס

אין אפליקציה נפרדת ל-Claude Code: הכול נמצא בלשונית **Code** באפליקציית Claude ל-[iOS](https://apps.apple.com/us/app/claude-by-anthropic/id6473753684) ול-[Android](https://play.google.com/store/apps/details?id=com.anthropic.claude). הטלפון לא מריץ קוד: הוא "שלט רחוק" לעבודה שרצה בענן או במחשב שלכם.

<Callout type="tip" title="קיצור להורדה">
הקלידו `/mobile` בתוך Claude Code, ויופיע קוד QR שמוביל לחנות האפליקציות המתאימה לטלפון שלכם.
</Callout>

יש שלוש דרכים לעבוד מהטלפון:

| דרך | למה מתחברים | מתי להשתמש |
| --- | --- | --- |
| **סשן ענן** | מחשב וירטואלי בענן | המאגר ב-GitHub, והמשימה צריכה לרוץ גם כשהטלפון בכיס |
| **Remote Control** | סשן Claude Code שרץ **על המחשב שלכם** | העבודה צריכה את הקבצים, הכלים או שרתי ה-MCP המקומיים שלכם |
| **Dispatch** | אפליקציית ה-Desktop במחשב | שולחים משימה בהודעה, והיא נפתחת כסשן באפליקציה (Pro ו-Max בלבד) |

### שליחת משימה מהטלפון

בלשונית **Code**: בוחרים מאגר וענף, כותבים את המשימה ושולחים. בערב, ליד המחשב, ממשיכים עם `claude --teleport`.

<Prompt>תוסיף לאתר המתכונים אפשרות להדפיס מתכון בצורה נקייה, בלי תפריטים ובלי כפתורים. תבדוק שזה עובד, ותפתח Pull Request עם תיאור בעברית</Prompt>

### Remote Control: לשלוט במחשב מהספה

Remote Control מחבר את הטלפון לסשן שרץ **במחשב שלכם**. הקוד והקבצים נשארים במחשב, ואתם רק שולחים הודעות ומאשרים פעולות מרחוק.

```bash title="שלוש דרכים להפעיל"
# סשן חדש עם שליטה מרחוק
claude --remote-control

# מצב שרת: ממתין לחיבורים מהטלפון או מהדפדפן
claude remote-control
```

```text title="בתוך סשן קיים"
/remote-control
```

(או בקיצור `/rc`.) בטרמינל תופיע כתובת, ובמצב שרת אפשר ללחוץ על **רווח** כדי להציג קוד QR. סורקים אותו בטלפון, או פותחים את הלשונית **Code** באפליקציה ובוחרים את הסשן מהרשימה.

<Callout type="tip" title="התראות לטלפון">
בזמן ש-Remote Control פעיל, Claude יכול לשלוח התראות לטלפון, למשל כשמשימה ארוכה מסתיימת או כשהוא צריך החלטה שלכם. אפשר גם לבקש במפורש: "תשלח לי התראה כשהבדיקות יסתיימו".
</Callout>

<Callout type="note" title="מגבלות במובייל">
- המחשב צריך להישאר **דולק**, עם Claude Code פתוח, כדי ש-Remote Control יעבוד. אם הוא נרדם, החיבור יחזור כשהוא יתעורר.
- חלק מהפקודות, כמו `/plugin` ו-`/resume`, עובדות רק בטרמינל.
- מהטלפון אי אפשר לבחור במצב Bypass permissions, וזה דווקא טוב.
</Callout>

## תרגיל: סיור בכל הממשקים

1. הורידו את אפליקציית ה-Desktop, פתחו סשן **Local** על אתר המתכונים, ובקשו שינוי קטן. סקרו אותו עם הערה על שורה אחת.
2. התקינו את תוסף Chrome, הפעילו `claude --chrome`, ובקשו מ-Claude לבדוק את `localhost:3000` ולדווח על שגיאות בקונסול.
3. דחפו את הפרויקט ל-GitHub, ושלחו משימה לענן עם `claude --cloud`.
4. התקינו את אפליקציית Claude בטלפון (`/mobile` מציג QR), ובדקו שאתם רואים את סשן הענן בלשונית **Code**.
5. כשהמשימה בענן מסתיימת, משכו אותה למחשב עם `claude --teleport`.
6. הפעילו `/remote-control` בסשן מקומי, והתחברו אליו מהטלפון.
