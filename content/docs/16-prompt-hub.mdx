# ספריית בקשות יומיומיות

הבקשות שתשתמשו בהן הכי הרבה, מוכנות להעתקה. כל אחת בנויה לפי כלל הזהב מפרק 4, ואפשר לסנן לפי נושא: דיבאג, ריפקטורינג, Git ו-PR, בדיקות, ו-RTL ועברית.

<Callout type="tip" title="איך להשתמש">
העתיקו בקשה, הדביקו ב-Claude Code, והחליפו את מה שבסוגריים המרובעים בפרטים שלכם. `@[קובץ]` הופך ל-`@` ושם הקובץ, למשל `@app/page.tsx`. בקשה שאתם משתמשים בה כל יום? הפכו אותה ל-Skill (פרק 11), או בנו אחת משלכם בבונה הבקשות (פרק 17).
</Callout>
