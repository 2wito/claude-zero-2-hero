## Quick cheat sheet: the 10 most important commands

```text title="To print or keep next to your computer"
claude              Start Claude Code in the current folder
claude -c           Continue the last conversation
Shift+Tab           Switch permission mode
@file               Attach a file to the request
!command            Run a terminal command inside the conversation
Esc / Esc Esc       Stop / go back to an earlier point
/clear              A new conversation between tasks
/compact            Summarize a long conversation to free up space
/context            What's taking up space in the context window
/help               All commands
```
