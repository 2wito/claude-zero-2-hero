# Everyday Prompt Library

The prompts you'll use most, ready to copy. Each one is built on the golden rule from chapter 4, and you can filter by topic: debugging, refactoring, Git and PRs, testing, and RTL & i18n.

<Callout type="tip" title="How to use it">
Copy a prompt, paste it into Claude Code, and replace whatever is in square brackets with your own details. `@[file]` becomes `@` plus the file name, for example `@app/page.tsx`. A prompt you use every day? Turn it into a skill (chapter 11), or build your own in the prompt builder (chapter 17).
</Callout>
